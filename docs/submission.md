## Задача 3

Что сделано:
- Реализован Google Apps Script в `apps-script/Code.gs`.
- Триггер реализован через пользовательское меню Google Sheets в `onOpen`: `GitHub Monitor -> Обновить репозитории / Очистить данные`.
- Используется GitHub REST API: `GET /users/{username}/repos?per_page=100&sort=updated`.
- Реализована логика: получение репозиториев, нормализация, сортировка по `updated_at`, запись в таблицу и расчет summary.
- Реализована запись статусов и ошибок в ячейку `B3` (включая `404`, `403`, `5xx`, формат данных, пустой username).

Ручная проверка Google Таблицы:
- успешная загрузка `octocat`;
- очистка данных через меню;
- пустой username;
- некорректный username;
- пользователь не найден (`404`).

Доступ работодателю:
- только на просмотр.
