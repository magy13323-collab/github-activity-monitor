# AI Workflow

В рамках этого проекта использовался Codex как AI-ассистент для:

- генерации стартовой структуры репозитория;
- реализации веб-утилиты на HTML/CSS/JavaScript;
- реализации Python-скрипта и Docker-конфигурации;
- подготовки Google Apps Script (структура функций, обработка ошибок, запись в Google Таблицу);
- подготовки и синхронизации проектной документации;
- предварительного ревью кода;
- последующей ручной проверки результата.

Итоговые решения дополнительно проверялись вручную:
- web-утилита (интерфейс, обработка ошибок, фильтры/сортировка);
- Python CLI и Docker-сценарий (запуск, JSON-выгрузка);
- Google Sheets + Apps Script (обновление, очистка, статус ошибок).
