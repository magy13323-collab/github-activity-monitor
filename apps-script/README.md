# Apps Script: GitHub Activity Monitor

Этот скрипт для Google Таблиц загружает публичные репозитории GitHub пользователя и записывает их в лист `Repositories`.

Используется публичный GitHub REST API:

`GET https://api.github.com/users/{username}/repos?per_page=100&sort=updated`

GitHub token и авторизация не используются.

## Что делает скрипт

- Добавляет пользовательское меню `GitHub Monitor` при открытии таблицы.
- Команда `Обновить репозитории` получает данные из GitHub API и заполняет лист `Repositories`.
- Команда `Очистить данные` очищает таблицу репозиториев и summary, не трогая username в `B1`.
- Показывает статус выполнения и ошибки в ячейке `B3`.

## Как настроить

1. Создайте Google Таблицу.
2. Откройте `Расширения -> Apps Script`.
3. Вставьте код из `apps-script/Code.gs` (или просто из `Code.gs`) в редактор Apps Script.
4. Сохраните проект.
5. Вернитесь в таблицу и обновите страницу.
6. На листе `Repositories` укажите GitHub username в ячейке `B1` (например: `octocat`).
7. В меню `GitHub Monitor` выберите `Обновить репозитории`.

## Какие права нужно разрешить

Скрипт работает только с текущей таблицей благодаря `@OnlyCurrentDoc`.

При первом запуске Google попросит разрешения:

- доступ к текущей таблице (чтение/запись, только текущий документ);
- выполнение внешнего HTTP-запроса через `UrlFetchApp`.

Scope `script.external_request` используется только для обращения к публичному GitHub API.

## Структура листа Repositories

- `A1`: `GitHub username`
- `B1`: значение username
- `A3`: `Status`
- `B3`: текст статуса
- `A4`: `Last update`
- `B4`: дата и время обновления
- `A6:G6`: заголовки репозиториев
- `A7:G...`: данные репозиториев
- `I1:J5`: summary-блок

## Что появится в таблице после запуска

- список репозиториев в `A7:G`;
- summary по количеству репозиториев, stars, forks и топу языков в `I1:J5`;
- статус в `B3`;
- время последнего обновления в `B4`.

## Обработка ошибок

Скрипт пишет понятный статус в `B3` для случаев:

- пустой или некорректный username;
- пользователь не найден (`404`);
- ограничение API / rate limit (`403`);
- временная недоступность GitHub API (`5xx`);
- неожиданный формат ответа или другие ошибки.

Ошибки не должны ломать таблицу: меню продолжает работать, а статус обновляется.

## Что предоставить в сдаче

- ссылку на Google Таблицу с доступом только на просмотр для работодателя;
- заполненный лист `Repositories` после запуска `Обновить репозитории`;
- пример, что статус и summary корректно обновляются.
